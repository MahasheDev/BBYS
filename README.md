Mahashe WinTweak — графическая утилита для тонкой настройки Windows, оптимизации системы, управления встроенными компонентами, проводником, Microsoft Store, установками приложений и дополнительными CMD-командами.

Проект ориентирован на минимальную зависимость от внешних скриптов: .reg, .bat, .ps1-логика по возможности встроена в Python-код. Внешними остаются только реальные утилиты, исполняемые файлы и ресурсные файлы, которые нельзя корректно заменить Python-логикой.

    Отключение HyperVisor.
    Отключение печати.
    Отключение Edge.

    Отключение предупреждений безопасности при открытии файлов.
    Отключение истории недавних файлов, папок и дисков.

    Игровой приоритет и игровые системные настройки.

Оптимизация

В оптимизацию входят и дополнительные системные изменения:

    отключение BitLocker-службы;
    отключение SysMain;
    отключение телеметрии;
    отключение Spynet;
    отключение Cortana;
    отключение Windows 11 AI через отдельную функцию;
    отключение удалённого помощника;
    отключение индексации дисков;
    отключение печати;
    отключение автообновления драйверов;
    настройка приватности Windows;
    скрытие поиска на панели задач;
    отключение погодного виджета/Widgets;
    настройка проводника на открытие раздела «Этот компьютер»;
    отключение частых папок и недавних файлов в быстром доступе;
    изменение поведения проводника Windows 10/11.

Если перед расширенной оптимизацией уже применялась простая оптимизация, базовый блок пропускается.
